# Squiggle on a phone

On a narrow screen the editor switches to one pane at a time. Everything you
can do on a computer is still there, laid out for a thumb.

## The top bar

| Control | What it does |
|---|---|
| Menu | Opens the menu as a sheet from the bottom |
| Project name | Tap to rename, when you are allowed to edit |
| Find blocks | Opens the block palette with a search box |
| Tiles | Opens the tile painter. It shows when the project uses World |
| Go, Stop | The green flag and the stop sign |

## The tabs along the bottom

| Tab | What is in it |
|---|---|
| Code | The code area for the selected sprite |
| Stage | The stage, with a row under it for full screen, the game buttons and the selected sprite's x and y |
| Sprites | The sprite list |
| Costumes | The costume and sound editors. It reads Backdrops when the Stage is selected |
| Room | Only in a room: who is here, the room's status and the chat. A count on the tab shows new chat lines |

If you join a room as a viewer, the editor keeps you on the Stage tab.

A small stage button keeps the game in view while you edit. Tap it again to
hide the small stage.

## Sheets

Menus, the tile painter, the scene list, the checker and the Together sheet
open as sheets from the bottom of the screen. Use **Make bigger** and **Make
smaller** to resize one, and **Close** to put it away.

## The tile painter sheet

Add the World extension and a level first. Then tap **Tiles** in the top bar.
The painter opens over the stage, and its tools sit in a sheet at the bottom.

| Tool | What it does |
|---|---|
| Paint | Paints the chosen tile |
| Erase | Clears a cell |
| Fill | Fills an area of the same tile |
| Box | Fills a rectangle |
| Pick | Picks the tile under your finger |
| Flag | Marks cells as solid, one way, hazard or goal |
| Spawn | Sets where the selected sprite starts |
| Camera | Draws the limits the camera stays inside for this scene |

Pick a layer to paint on: **Back** is behind the sprites, **Main** is the layer
sprites stand on, and **Front** is in front of them. **Undo**, **Redo**,
**Grid** and **Done** sit with the tools.

The painter has its own view, so you can look around a big level without
moving the game camera:

- Tap to paint one cell, or drag to keep painting.
- Pinch to zoom and drag with two fingers to pan. A stroke the first finger
  started is dropped when the second finger lands, so a pinch never paints.
- With a keyboard, plus and minus zoom and 0 goes back to the camera.

If the painter says "Add a level with the World blocks to paint tiles.", the
project has no level yet. If it says "Add costumes to the tileset to paint with
them.", the tileset is empty.

## Scenes

The Scenes button opens the scene list as a sheet. From there you can add a
scene, rename it, move it left or right, delete it, or choose **Use stage**.

## Playing games on a phone

When a game listens for keys, the player shows on-screen controls on a touch
screen: a pad for the arrows and WASD, and up to four action buttons for the
other keys the game uses. In portrait they sit under the stage, and in
landscape along the sides of it. On a computer with a mouse they stay hidden.
In the editor, **Game buttons** on the Stage tab shows or hides the on-screen
arrow and space buttons.
